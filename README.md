# STM32-LCD-Display

## Project Overview

This project demonstrates interfacing an LCD display with an STM32 microcontroller using STM32CubeIDE and Embedded C.

## Objectives

- Interface an LCD with STM32
- Display text and data on the LCD
- Configure STM32 GPIO pins
- Understand LCD interfacing
- Develop embedded firmware

## Hardware Used

- STM32 Development Board
- LCD Display
- Jumper Wires
- USB Cable

## Software Used

- STM32CubeIDE
- Embedded C
- STM32 HAL Library

## Concepts Used

- STM32 GPIO
- LCD Interfacing
- Embedded C
- Microcontroller Programming
- Hardware-Software Interfacing

## Working

The STM32 microcontroller is configured to communicate with the LCD through GPIO pins.

The firmware initializes the LCD and sends commands and data to display the required information.

## Result

Successfully interfaced the LCD with the STM32 microcontroller and displayed the required information.
